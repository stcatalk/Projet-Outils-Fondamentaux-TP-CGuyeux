# Calculateur de la position du "StrongHold"
Ce projet calcul la position de la strcuture "StrongHold" dans un monde du jeu Minecraft.
Il utilise pour ce faire l'angle entre le stronghold et le joueur, connu grâce à un objet en jeu, à 2+ position différentes

## Requis
python 3

matplotlib

## Utilisation
1. Éxecuter le programme
> python calculStronghold.py

2. Entrer le nombre de lancers

3. Entrer la position et l'angle de chaque lancer
